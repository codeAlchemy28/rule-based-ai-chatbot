**DecodeBot**
A rule-based AI chatbot developed as part of the DecodeLabs Artificial Intelligence Internship.
DecodeBot is a simple rule-based chatbot that uses predefined rules and conditional statements to respond to user inputs.

The chatbot demonstrates fundamental Artificial Intelligence concepts such as:
- Rule-based decision making
- Conditional statements
- User input processing
- Continuous interaction loops

Features:
- Responds to common greetings
- Answers basic questions
- Handles different input cases
- Ignores common punctuation at the end of user questions
- Provides a response for unknown inputs
- Supports exit commands
- Runs continuously until the user chooses to exit

Technologies Used:
- Python 3
- Python IDLE
- Conditional statements (`if`, `elif`, `else`)
- `while` loop
- String manipulation


**Example Conversation:**

Welcome to DecodeBot!
Type 'bye', 'exit', or 'quit' to end the chat.

You: Hello!

Bot: Hello! How can I help you?

You: what is your name ??

Bot: I'm DecodeBot, a rule-based AI chatbot.

You: HOW ARE YOU ?

Bot: I'm doing great! Thanks for asking.

You: Thank you!

Bot: You're welcome!

You: bye

Bot: Goodbye! Have a great day!
